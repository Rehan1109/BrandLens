# BrandLens 🛡️
### Smart Brand Compliance Review Platform

BrandLens helps teams review marketing content before publishing by checking it against brand rules, approved facts, and prohibited terms.

## 🎯 Problem Statement
Marketing teams often struggle with inconsistent brand tone, outdated product information, and unverified claims across content created by employees, agencies, and AI tools.

## 💡 Our Solution
BrandLens provides a simple platform where content creators can check their drafts and brand managers can review submissions before approval.

## ✨ Key Features
- **Brand Rule Management:** Manage prohibited terms and approved product facts.
- **Compliance Checker:** Detect prohibited words and mismatched product information.
- **Content Submission:** Submit drafts for brand manager review.
- **Review Dashboard:** View submitted content and its review status.
- **Approval Workflow:** Approve content or request changes.
- **Local Data Storage:** Save project data using browser localStorage.

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Open the Creator and Brand Manager pages.
5. Add a draft, check compliance, submit it, and review it from the manager dashboard.

**Note:** Open both pages using the same Live Server origin for browser storage synchronization.
